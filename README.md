## 🚀 本地启动器（通用）

任意一款游戏的网页代码解压后，把下面两个文件放进**同一文件夹**（和 `index.html` 同级），双击 `开始游玩.cmd` 即可在本地浏览器运行：

- [`_serve.mjs`](./_serve.mjs) — 本地静态服务器（Node.js），自动处理 MIME / 端口 / Range 请求
- [`开始游玩.cmd`](./开始游玩.cmd) — Windows 一键启动器

> 运行前需安装 Node.js LTS：https://nodejs.org/
> 详细图文步骤见 → [本地运行教程](./本地运行教程.md)
